Cuéntanos qué información necesitas

Este formulario es solo una maqueta de interfaz para el proyecto académico. No está conectado al Centro de Salud y no envía ni almacena tus datos.

Formulario de demostración

No ingreses datos personales o información médica real. Para orientación efectiva, llama al (074) 424430.

Prototipo sin conexión: la información introducida no se transmite ni se guarda. El equipo debe conectar un canal institucional seguro antes de usar este formulario con pacientes.
No uses este formulario para urgencias ni para compartir datos de salud.
Los campos con * son obligatorios para esta demostración.

¿Cómo solicitar orientación?

  1. Llama al número institucional para consultar el servicio y horario.
  2. Pregunta qué documentos o requisitos necesitas según tu atención.
  3. Confirma si la consulta requiere acudir presencialmente o puede coordinarse por telemedicina.

Antes de acudir

  • Consulta los requisitos vigentes por teléfono.
  • Ten a mano tu documento de identidad y, si corresponde, información de afiliación al SIS.
  • No compartas datos personales por canales no verificados.
